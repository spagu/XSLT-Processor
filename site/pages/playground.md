Paste an XML document and an XSLT 1.0 stylesheet, or start from one of the
examples. The transformation runs in this page with the library's browser
bundle, not with the browser's native `XSLTProcessor`, so the result is the one
your users get after Chrome removes native XSLT. Nothing is uploaded, and the
page keeps working without a network connection once it has loaded.
