# @tradik/xslt3

XSLT 3.0 and XPath 3.1 in JavaScript. One engine for XSLT 3.0 and 2.0
stylesheets, and 1.0 ones in backwards-compatible mode, with no runtime
dependencies.

**In development; not published yet.** The design, the scope and the
milestones are in [docs/XSLT3.md](../../docs/XSLT3.md).

For XSLT 1.0 with the browser's `XSLTProcessor` API and Chrome (libxslt)
behaviour, use [@tradik/xslt-processor](../../README.md).
